# Mi Servers

Source du site [miservers.github.io](https://miservers.github.io/), adaptée du site [miservers.gitlab.io](https://miservers.gitlab.io/).

Le site est construit avec Jekyll et publié via `.github/workflows/pages.yml` après chaque modification de `master`.

Pour lancer le site localement : `bundle install && bundle exec jekyll serve`.
